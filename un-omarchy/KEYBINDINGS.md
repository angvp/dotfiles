# Keybindings

| `Super + Shift + D` | Docker (lazydocker) |
| `Super + Shift + G` | Signal |
| `Super + Shift + O` | Obsidian |
| `Super + Shift + /` | Passwords (1Password) |

## Windows

| Keys | Action |
|------|--------|
| `Super + W` | Close window |
| `Ctrl + Alt + Delete` | Close all windows |
| `Super + T` | Toggle floating / tiling |
| `Super + F` | Full screen |
| `Super + Ctrl + F` | Tiled full screen |
| `Super + Alt + F` | Full width |
| `Super + O` | Pop out window (float + pin) |
| `Super + J` | Toggle split direction |
| `Super + P` | Pseudo-tile window |
| `Super + L` | Toggle workspace layout (dwindle ↔ scrolling) |
| `Super + -` | Expand window (left) |
| `Super + =` | Shrink window (left) |
| `Super + Shift + -` | Shrink window (up) |
| `Super + Shift + =` | Expand window (down) |
| `Super + drag (LMB)` | Move window |
| `Super + drag (RMB)` | Resize window |

### Focus

| Keys | Action |
|------|--------|
| `Super + ←↑↓→` | Move focus |
| `Alt + Tab` | Next window |
| `Alt + Shift + Tab` | Previous window |

### Groups

| Keys | Action |
|------|--------|
| `Super + G` | Toggle window group |
| `Super + Alt + G` | Move window out of group |
| `Super + Alt + ←↑↓→` | Move window into group |
| `Super + Alt + Tab` | Next window in group |
| `Super + Alt + Shift + Tab` | Previous window in group |
| `Super + Ctrl + ←` | Group focus left |
| `Super + Ctrl + →` | Group focus right |
| `Super + Alt + 1–5` | Switch to group window by number |
| `Super + Alt + scroll` | Scroll through group windows |

## Workspaces

| Keys | Action |
|------|--------|
| `Super + 1–0` | Switch to workspace 1–10 |
| `Super + Tab` | Next workspace |
| `Super + Shift + Tab` | Previous workspace |
| `Super + Ctrl + Tab` | Last used workspace |
| `Super + scroll` | Scroll through workspaces |
| `Super + Shift + 1–0` | Move window to workspace 1–10 |
| `Super + Shift + Alt + 1–0` | Move window silently to workspace 1–10 |
| `Super + S` | Toggle scratchpad |
| `Super + Alt + S` | Move window to scratchpad |

### Multi-monitor

| Keys | Action |
|------|--------|
| `Ctrl + Alt + Tab` | Focus next monitor |
| `Ctrl + Alt + Shift + Tab` | Focus previous monitor |
| `Super + Shift + Alt + ←↑↓→` | Move workspace to monitor |
| `Super + Shift + ←↑↓→` | Swap window with neighbor |
